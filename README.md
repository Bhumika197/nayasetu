## Overview

**NyayaSetu** is a Government-of-India standard, compliance-first legal technology platform prototype designed to bridge the legal literacy gap, simplify citizen court procedures, and streamline lawyer-client case collaboration in strict compliance with the **Advocates Act, 1961 (Section 29/33)** and **Bar Council of India Rule 36 (non-solicitation)**.

The interface is engineered according to the official **Guidelines for Indian Government Websites (GIGW)** and **Digital India** UI/UX standards.

---

## Key Modules & Capabilities

### 1. Citizen Services Portal
- **AI Legal & Tax Literacy Assistant**: Translates natural language citizen grievances into governing statutes, sections, court jurisdiction, and actionable remedies under Bharatiya Nyaya Sanhita (BNS) and special acts.
- **Court-Ready Document Drafter**: Self-help statutory drafting for Section 138 NI Act notices, RTI Form A applications, Consumer Protection grievances, tenancy notices, and sworn affidavits.
- **Bhashini Multilingual Voice Assistant**: Regional language speech interface powered by the Government of India National Language Translation Mission (NLTM).
- **eCourts Live Case Status Tracker**: 16-character CNR lookup integrated with the National Judicial Data Grid (NJDG) for real-time hearing dates, order sheets, and chronological court diaries.
- **Bhulekh & Land Records Gateway**: Digital India Land Records Modernization Programme (DILRMP) 7/12 extract and mutation verification.
- **Statutory Compliance Calendar**: Limitation Act, 1963 deadline calculators with calendar ICS export.
- **Private Case Rooms (Litigant View)**:
  - Confidential, privileged case rooms (Room #NYAYA-701).
  - Document upload station supporting sample case records (`Example_Files/`) and local files.
  - Join new case chambers using confidential invitation tokens generated by advocates.
  - End-to-end encrypted direct messaging with counsel.

### 2. Advocate Desk (Legal Practice Management)
- **Advocate Case Rooms & Chamber Management**:
  - Multi-room overview with active status badges.
  - Create new confidential case rooms, name matters, and generate shareable client invitation codes (e.g. `NYAYA-703-GQ`).
  - **Document Verification Console**: Inspect client submissions and mark documents as **Accepted** or **Rejected** (with client feedback).
  - **Document Request Console**: Issue requests for specific records with statutory due dates.
- **Active Litigation Docket**: Track pending court filings, CNR numbers, presiding benches, and procedural stages.
- **Billable Hours & Tasks Tracker**: Real-time timer, activity categorization, and automated billing fee calculation.

## Running the Prototype Locally

The prototype runs with zero external dependencies in any modern web browser:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/DevJain1206/Nyayasetu-Prototype.git
   cd Nyayasetu-Prototype
   ```

2. **Serve locally via Python (recommended)**:
   ```bash
   python -m http.server 3000
   ```

3. **Access in browser**:
   Open [http://localhost:3000](http://localhost:3000) in your web browser.
